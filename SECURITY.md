# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Preferred: use GitHub's **Report a vulnerability** button on this repository's Security tab (private vulnerability reporting). `[Maintainer: turn this on under Settings > Code security, or remove this line.]`
- Or email `[SECURITY CONTACT EMAIL]`.

Tell us what you found, how to reproduce it and what it could affect. Please do not access other people's data, run denial-of-service tests, or use real personal data in your testing.

We aim to acknowledge reports within `[5 working days]` and to keep you told of progress. This is a small proof of concept with no bug bounty.

## What is in scope

- The A3 Workbench at https://stephjm24.github.io/a3-dashboard/
- The A3 Coach app in `src/`, which is not deployed publicly yet
- The workflows and scripts in this repository
